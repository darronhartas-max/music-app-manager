Music App Manager — User Guide

Your personal launcher and catalogue for music production software and audio plugins.

📖 Introduction

🏠 Overview

Music App Manager is a desktop application built for music producers. It gives you a single, beautiful dashboard to launch your music apps, browse your plugin library, and keep everything organised by category.

🎹
App Launcher
One-click launch for all your music apps, organised into categories you define.
🔌
Plugin Library
Catalogue every VST, VST3, and AU plugin on your system with full details.
📡
Auto Scanner
Reads your app bundles directly to detect music software and identify manufacturers.
🔍
Fuzzy Search
Instantly find any app or plugin with smart matching — even with partial or approximate names.
✏️
Drag & Drop
Reorder your app cards into exactly the layout you want using Edit Mode.
⭐
Favourites
Star your most-used apps and filter to them instantly.
🚀 Getting Started

🚀 First Run

When you launch Music App Manager for the first time with an empty library, a welcome screen will guide you through setup. Here's the recommended flow:

1
Go to the Tools tab

Click Tools in the navigation bar at the top of the app.

2
Scan for Music Apps

Under 🎵 App Scanner, click Scan for Music Apps. The app scans your /Applications folder, reads each app's bundle to identify the software and manufacturer, and presents a list for you to review.

3
Select and add apps

Review the detected apps, assign categories, and click Add Selected Apps. All chosen apps appear immediately on the Apps tab.

4
Scan for Plugins

Under 🔍 Plugin Scanner, click Scan for Plugins. The scanner checks all standard plugin directories (VST, VST3, AU for both system-wide and user-level paths). Click Add X Plugins when done.

5
You're done!

Your library is populated. Click any app card to launch it, use the search bar to find plugins, and use Edit Mode to reorganise your layout.

💡 Tip: If the scanner misses an app (e.g. installed in a non-standard location), use the + Add App button on the Apps tab to add it manually.
🎹 Apps

🎹 Apps Tab

The Apps tab is your main launcher. Apps are displayed as cards grouped by category.

Launching an App

Click any app card to launch the application immediately. Recently launched apps are highlighted with a subtle glow, and appear in the Recent filter.

Quick Filters

Use the filter buttons in the toolbar to view:

  • All — every app in your library
  • Favourites ⭐ — apps you've starred
  • Recent 🕐 — apps launched in this session

Favouriting an App

Hover over any app card — a ☆ star button appears in the top-left corner. Click it to toggle the app as a favourite. Stars persist between sessions.

Adding an App Manually

Click + Add App in the toolbar. Fill in the name, path (use the Browse button to pick the .app file), manufacturer, category, and an emoji icon. You can also upload a custom image icon using the 🖼️ Upload button.

Editing an App

Enable Edit Mode (see below), then click any app card to open the edit panel where you can change its name, category, manufacturer, or icon.

🔌 Plugins

🔌 Plugins Tab

The Plugins tab displays your full audio plugin library in a searchable, filterable table.

Filtering Plugins

Use the format filter buttons at the top to narrow the list:

  • All — full library
  • Instruments — synths, samplers, virtual instruments
  • Effects — reverbs, compressors, EQs, delays
  • VST / VST3 / AU — filter by format

Plugin Details

Click any plugin row to open its detail panel. You can view and edit the plugin's type, format, manufacturer, notes, and path. Use the notes field to record licence information, serial numbers, or other reminders.

Note: The plugin scanner reads metadata from the file path and name. For precise type identification (Instrument vs Effect), edit the plugin's details manually after scanning.
🔍 Search

🔍 Search

The search bar in the header works across both Apps and Plugins depending on which tab is active.

Fuzzy Search (Apps)

On the Apps tab, search uses a fuzzy matching algorithm that scores results by:

  • App name — weighted highest
  • Manufacturer name — weighted medium
  • Category name — weighted lower

This means searching for "cher" will still find Cherry Audio synths even without typing the full name.

Search History

Click the search box when it's empty to see your recent searches. Click any item to repeat that search. Click Clear to wipe the history.

Clear Search

Click the ✕ button that appears at the right of the search box, or clear the field manually, to return to the full app/plugin list.

⚙️ Tools

📡 Scanning

App Scanner

Found in Tools → 🎵 App Scanner. Scans /Applications and detects music software using three strategies:

1
Apple Category Flag

Reads each app's Info.plist and checks LSApplicationCategoryType. Any app Apple has categorised as public.app-category.music or audio is detected regardless of its display name.

2
Bundle ID Matching

Checks the app's bundle identifier (e.g. com.cherryaudio.*) against a database of 80+ known music publisher domains. This catches every Cherry Audio synth, Arturia product, iZotope tool, etc.

3
Keyword Matching

If neither of the above match, the app name is checked against an extended list of music production keywords as a fallback.

Plugin Scanner

Found in Tools → 🔍 Plugin Scanner. Scans these directories:

  • /Library/Audio/Plug-Ins/VST3
  • /Library/Audio/Plug-Ins/VST
  • /Library/Audio/Plug-Ins/Components (AU)
  • ~/Library/Audio/Plug-Ins/VST3
  • ~/Library/Audio/Plug-Ins/VST
  • ~/Library/Audio/Plug-Ins/Components
✏️ Edit Mode

✏️ Edit Mode & Drag-Drop

Click the ✏️ Edit Mode button in the Apps toolbar to enter Edit Mode.

Reordering Apps

In Edit Mode all app cards become draggable (the cursor changes to a grab hand). Drag any card left or right to reposition it within a category. A blue indicator line shows where the card will land. You can also drag cards across category boundaries to move an app to a different category.

Editing App Details

In Edit Mode, clicking a card opens the edit form instead of launching the app. From here you can change the name, category, manufacturer, or icon.

Exiting Edit Mode

Click ✏️ Edit Mode again (it will appear highlighted/active) to return to normal launch mode. Your ordering is saved automatically.

💡 Tip: You can use the fuzzy search while in Edit Mode — search results are also draggable.
📁 Organisation

📁 Categories

Categories group your apps on the Apps tab. Manage them in Tools → 📁 Category Manager.

Adding a Category

Click + Add Category and enter a name. The new category appears immediately and is available when adding or editing apps.

Renaming a Category

Click the ✏️ pencil icon next to a category name. Type the new name and press Enter or click the confirm button.

Reordering Categories

Use the ↑ and ↓ arrow buttons next to each category to move it up or down in the list. The order shown in the Category Manager is the order categories appear on the Apps tab.

Deleting a Category

Click the 🗑️ delete button. Apps in that category will need to be reassigned — the scanner will prompt you if any apps become uncategorised.

🖼️ Icons

🖼️ App Icons

Music App Manager extracts the real icon from each app's bundle automatically — no icon library needed.

Automatic Extraction (during scan)

When you run the App Scanner, each detected app's .icns icon file is read from inside the bundle and stored as a 64×64 image. You see the familiar, real app icon on every card.

Refresh Icons

If you've manually added apps (which default to the 🎵 emoji), or if icon data is missing, go to Tools → 💾 Configuration → 🖼️ Refresh App Icons. This re-extracts icons for every app in your library and saves the result.

Custom Icons

When adding or editing an app manually, click 🖼️ Upload next to the icon field to choose any image file from your system. JPG, PNG, and WebP are all supported.

💡 Tips

💡 Tips & Tricks

Use search history for quick access

Your last 10 searches are saved. Click the search bar when empty to see them — great for jumping back to a manufacturer search you use often.

Rescan after installing new software

After installing a new DAW or plugin suite, run the App Scanner and Plugin Scanner again. Already-catalogued items are skipped automatically — only new software is added.

Use Clean Up Missing Apps

If you uninstall software, go to Tools → Configuration → 🧹 Clean Up Missing Apps to remove any entries whose files no longer exist.

Export your config as a backup

Use Tools → Configuration → 📤 Export Config to save a copy of your entire library. Store it alongside your project files as a snapshot of your studio setup.

❓ FAQ

❓ Frequently Asked Questions

The scanner only found a few apps — why?

The scanner reads /Applications only. If your music software is installed elsewhere (e.g. in a subfolder or on an external drive), use + Add App to add it manually.

My plugins all show as "Unknown" type

Plugin type (Instrument vs Effect) is difficult to determine automatically from the file alone. Click any plugin row and set the type manually. This also lets you add notes like serial numbers or licence details.

Icons aren't showing for manually-added apps

Go to Tools → Configuration → 🖼️ Refresh App Icons. This will extract real icons from all app bundles in your library, including manually-added ones.

I dismissed the welcome screen — how do I see it again?

Open your browser's developer tools or Terminal and run: localStorage.removeItem('mam-welcome-shown'), then restart the app.

Can I use Music App Manager on Windows?

The core app is cross-platform but the scanner is currently optimised for macOS (reads .app bundles and Info.plist). Windows support is planned for a future phase.

Where is my library data stored?

All data is saved to config/apps-config.json inside the app's folder. Back it up using Export Config in the Tools tab.
