Music App Manager — User Guide

Your complete guide to launching music applications, creating multi-app Studio Sessions, inspecting audio plugins, managing licenses, and comparing studio rigs on macOS and Windows PC.

🚀 1. Getting Started

When you first open Music App Manager, populate your library in two quick steps from the ⚙️ Tools tab:

  1. Scan for Music Apps: Automatically discovers DAWs, standalone synths, guitar amp sims, and audio utilities in /Applications (macOS) or Start Menu / Program Files (Windows), while automatically extracting and refreshing high-resolution app icons and on-disk bundle sizes.
  2. Scan for Plugins: Scans standard and custom folders for VST3, AU, CLAP, AAX, and VST2 plugins, identifying manufacturers, versions, file sizes, and CPU architectures.

🎹 2. Apps Dashboard & Studio Sessions

  • Launch Any App: Click any app card in normal mode to launch it immediately.
  • 🚀 Studio Session Multi-App Bundles: Click 🚀 New Session on the Apps toolbar to create custom 1-click session presets (e.g., "🎸 Guitar Jam Rig", "🎙️ Mixing Session", or "🎹 Synth Sound Design"). Check off any combination of apps, and click your saved session pill in the 🚀 Studio Sessions bar to launch all of those apps simultaneously. Click ✏️ on any session pill to edit or delete it.
  • Group by Category or Manufacturer: Use the toolbar toggle to view apps grouped by workflow category (DAWs, Synths, Guitar & Bass, Audio Tools, Utilities) or by manufacturer (Arturia, Native Instruments, Ableton, etc.).
  • Drag & Drop Categories: In By Category view, grab any category header by its drag handle (⠿) and drag it up or down onto another category section to reorder your categories directly on the Apps page.
  • Right-Click Context Menu: Right-click any app card at any time to Launch, Toggle Favorite, Edit Details, Show in Finder / Explorer, or Remove from Library.

✏️ 3. What Does "Edit / Reorder" Mode Do?

Clicking the ✏️ Edit / Reorder button on the Apps toolbar switches the dashboard from Launch Mode into Customize Mode:

  • Safe Clicking (No Accidental Launches): While Edit Mode is active, clicking an app card opens its Edit App window instead of launching the application.
  • Drag & Drop App Cards: Drag any app card left or right (or even into a different category) to arrange your cards in your preferred order.
  • Drag & Drop Categories: Drag category headers by their ⠿ handle or use the ⬆️ ⬇️ buttons on each category header.
💡 Click ✅ Done Editing (or press Cmd/Ctrl + E) when finished to return to one-click app launching.

🔌 4. Plugins Catalog, Sorting & Disk Space Size

  • Sort by Any Column Header: Click any column title (⭐, Name, Type, Format, Manufacturer, Version, Size, Architecture, Rating, or Notes) to sort the table alphabetically or numerically. Clicking the same column header again toggles between ascending (▲) and descending (▼). By default, plugins are ordered alphabetically by Name (A–Z).
  • 💾 Disk Space Size Column: Shows the exact on-disk footprint (KB, MB, or GB) of every plugin. Sort by Size to immediately see which plugins consume the most storage.
  • Grouped vs. Flat List View:
    • Grouped (Default): Combines identical plugins installed in multiple formats (e.g., VST3 + AU + AAX) into a single clean row with format badges and combined disk size.
    • Flat List: Shows every individual plugin file on disk as its own row.
  • 🔄 One-Click Rescan & Per-Format Reveal: Click 🔄 Rescan Plugins right on the Plugins toolbar to scan and sync new plugins in one click. Click any plugin row to inspect all of its installed format locations with a dedicated 📂 Reveal button next to each format file path.

🧊 5. Version Mismatches, Redundant VST2s & Plugin Freezer Vault

  • 🔀 Version Mismatch Inspector: Automatically detects when two formats of the same plugin (e.g., AU vs. VST3) have different version numbers on disk. Click the 🔀 Version Mismatch filter pill for a reassuring, plain-English Resolution Guide and 1-click vendor updater buttons.
  • 📦 Redundant VST2 Inspector: Click 📦 Redundant VST2 to find legacy .vst files where you already have the modern VST3 version installed.
  • ⚠️ Intel Only (Rosetta) Filter: On Apple Silicon Macs (M1–M5), click ⚠️ Intel Only to spot legacy Intel-only plugins.
  • 🧊 Plugin Freezer / Vault (Disable Without Uninstalling): Click the 🧊 button in the Actions column (or inside the plugin details modal next to a specific format) to move unused or trial plugins out of your active system plugin folders into the safe Plugin Vault. Your DAW will boot faster and skip them, and clicking 🔥 restores them to their original folder in one click.

🔑 6. License, Serial Key & Account Vault

Both the Edit App and Edit Plugin modals include a built-in 🔑 License, Serial Key & Account Vault:

  • Record the License Type (Full License, iLok, Serial Key, Vendor Product Manager, Subscription, Hardware Dongle, Freeware, Demo/Trial).
  • Save your Registered Account / Email or iLok ID alongside your Serial Number / Activation Code with a 1-click 📋 Copy button.
  • Items with saved license details display a 🔑 badge on the dashboard and plugin table. All data is stored 100% locally in your configuration file.

📂 7. Adding & Amending Categories (Settings)

Open the ⚙️ Tools tab and scroll to 📂 Category Manager to manage your categories:

  • Add a New Category: Type the new category name into the input box and click ➕ Add Category (or press Enter).
  • Amend / Rename a Category: Edit the text inside any category's name box and click its 💾 Save Name button (or press Enter).
  • Reorder or Delete Categories: Use the ⬆️ / ⬇️ buttons to move categories up or down, or click 🗑️ to remove a category.

🛠️ 8. Update Centers, Backup/Restore & Two-Machine Rig Comparison

  • 🔄 Update & License Centers Hub: Automatically groups your installed vendor software centers (Arturia Software Center, Cherry Audio Sync, UA Connect, IK Product Manager, KORG Software Pass, GForce Installer, Reason Companion, Muse Hub, iLok License Manager, Native Access, Waves Central, etc.) inside ⚙️ Tools for 1-click launching.
  • 📤 Export & 📥 Import Config JSON: Save a complete backup of your library, categories, Studio Sessions, ratings, and License Vault, and restore it anytime.
  • 💻 Two-Machine Rig Comparison: Load an exported Config JSON from a second computer (e.g., Studio Desktop vs. Live MacBook or Windows PC) to see a side-by-side report of missing apps, missing plugins, and version differences before opening a DAW project.

⌨️ 9. Keyboard Shortcuts

  • Cmd/Ctrl + 1 — Switch to Apps Tab
  • Cmd/Ctrl + 2 — Switch to Plugins Tab
  • Cmd/Ctrl + 3 — Switch to ⚙️ Tools Tab
  • Cmd/Ctrl + F — Focus Search Bar
  • Cmd/Ctrl + N — Add New App
  • Cmd/Ctrl + E — Toggle Edit / Reorder Mode
  • Cmd/Ctrl + ? — Show Keyboard Shortcuts Overlay
  • Esc — Close Active Modal or Menu
