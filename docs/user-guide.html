Music App Manager — User Guide

Everything you need to organize your music applications, reorder categories, and inspect your audio plugins on macOS and Windows PC.

🚀 1. Getting Started

When you first open Music App Manager, populate your library in two quick steps from the ⚙️ Tools tab:

  1. Scan for Music Apps: Automatically discovers DAWs, standalone synths, guitar amp sims, and audio utilities in /Applications (macOS) or Start Menu / Program Files (Windows), complete with real app icons.
  2. Scan for Plugins: Scans standard and custom folders for VST3, AU, CLAP, AAX, and VST2 plugins, identifying manufacturers, versions, and CPU architectures.

🎹 2. Apps Dashboard & Category Ordering

  • Launch Any App: Click any app card in normal mode to launch it immediately.
  • 🚀 Studio Session Multi-App Bundles: Click 🚀 New Session on the Apps toolbar to create custom 1-click session presets (e.g., "🎸 Guitar Jam Rig" or "🎙️ Mixing Session") that launch multiple applications together simultaneously.
  • Group by Category or Manufacturer: Use the toolbar toggle to view apps grouped by workflow category (DAWs, Synths, Guitar & Bass, Audio Tools, Utilities) or by manufacturer (Arturia, Native Instruments, Ableton, etc.).
  • Drag & Drop Categories: In By Category view, grab any category header by its drag handle (⠿) and drag it up or down onto another category section to reorder your categories directly on the Apps page.
  • Right-Click Context Menu: Right-click any app card at any time to Launch, Toggle Favorite, Edit Details, Show in Finder / Explorer, or Remove from Library.

✏️ 3. What Does "Edit / Reorder" Mode Do?

Clicking the ✏️ Edit / Reorder button on the Apps toolbar switches the dashboard from Launch Mode into Customize Mode:

  • Safe Clicking (No Accidental Launches): While Edit Mode is active, clicking an app card opens its Edit App window instead of launching the application.
  • Drag & Drop App Cards: Drag any app card left or right (or even into a different category) to arrange your cards in your preferred order.
  • Drag & Drop Categories: Drag category headers by their ⠿ handle or use the ⬆️ ⬇️ buttons on each category header.
  • Quick Edit & Delete Buttons: Every card displays ✏️ Edit and 🗑️ buttons so you can quickly rename apps, move them to another category, change their icon, or remove them.
💡 Click ✅ Done Editing (or press Cmd/Ctrl + E) when finished to return to one-click app launching.

🔌 4. Plugins Catalog & Column Sorting

  • Sort by Any Column Header: Click any column title (⭐, Name, Type, Format, Manufacturer, Version, Size, Architecture, Rating, or Notes) to sort the table alphabetically or numerically. Clicking the same column header again toggles between ascending (▲) and descending (▼). By default, plugins are ordered alphabetically by Name (A–Z).
  • Grouped vs. Flat List View:
    • Grouped (Default): Combines identical plugins installed in multiple formats (e.g., VST3 + AU + AAX) into a single clean row with format badges.
    • Flat List: Shows every individual plugin file on disk as its own row.
  • Apple Silicon vs. Intel (Rosetta) Detection: On Apple Silicon Macs (M1–M5), the Architecture column shows whether each plugin binary is Apple Silicon, Universal, or Intel (Rosetta). Click the ⚠️ Intel Only filter button to immediately find legacy plugins.
  • Local Version Mismatch & Redundant VST2 Inspector: Automatically compares installed formats (e.g., VST3 vs. AU vs. AAX) of the same plugin on disk. Use the 🔀 Version Mismatch filter button to spot plugins where one format is outdated compared to another, or click 📦 Redundant VST2 to find legacy VST2 files where the modern VST3 version is already installed.
  • One-Click Rescan, Plugin Freezer Vault & Per-Format Reveal: Click 🔄 Rescan Plugins right on the Plugins toolbar to scan and sync new plugins in one click. Click 🧊 in the Actions column (or inside the plugin details modal) to temporarily freeze/disable unused plugins into the 🧊 Frozen Vault so your DAW starts faster, and click 🔥 at any time to restore them.
  • Rate, Note, License Vault & Export: Click any plugin row to give it a 1–5 star rating, store its 🔑 License Type, Registered Email/Account, and Serial Key (with 1-click Copy), save personal notes, or click 📄 Export CSV to save a spreadsheet of your plugin catalog.

📂 5. Adding & Amending Categories (Settings)

Open the ⚙️ Tools tab and scroll to 📂 Category Manager to manage your categories:

  • Add a New Category: Type the new category name into the "New category name..." box and click ➕ Add Category (or press Enter).
  • Amend / Rename a Category: Edit the text inside any category's name box and click its 💾 Save Name button (or press Enter). All apps inside that category are automatically kept in the renamed category.
  • Reorder or Delete Categories: Use the ⬆️ / ⬇️ buttons to move categories up or down, or click 🗑️ to remove a category.

🛠️ 6. Update Centers, Custom Folders & Maintenance

  • 🔄 Update & License Centers Quick-Launch Hub: Automatically groups your installed vendor software centers and license managers (Arturia Software Center, Cherry Audio Sync, UA Connect, IK Product Manager, KORG Software Pass, GForce Installer, Reason Companion, Muse Hub, iLok License Manager, Native Access, Waves Central, etc.) inside the ⚙️ Tools tab so you can launch any updater in one click.
  • Custom Scan Folders: Add secondary hard drives or custom VST2/VST3 folders under 📁 Custom Scan Folders so the scanner includes them.
  • Clean Up Missing Apps / Plugins: Checks every item in your library against your hard drive and lets you remove uninstalled entries in one click.
  • Export & Import Config JSON: Save a complete backup of your categories, app order, ratings, and plugin notes using 📤 Export Config JSON, and restore or transfer it at any time using 📥 Import Config.
  • Version Tracking: The ℹ️ About section at the bottom of Tools displays the live application version and platform architecture.

⌨️ 7. Keyboard Shortcuts

  • Cmd/Ctrl + 1 — Switch to Apps Tab
  • Cmd/Ctrl + 2 — Switch to Plugins Tab
  • Cmd/Ctrl + 3 — Switch to ⚙️ Tools Tab
  • Cmd/Ctrl + F — Focus Search Bar
  • Cmd/Ctrl + N — Add New App
  • Cmd/Ctrl + E — Toggle Edit / Reorder Mode
  • Cmd/Ctrl + ? — Show Keyboard Shortcuts Overlay
  • Esc — Close Active Modal or Menu
